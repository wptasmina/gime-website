# GIME Website

## Live Preview

Check out the live version of the website here: [GIME Website] (https://wptasmina.github.io/gime-website)


This repository contains the source code for the GIME website. The website is built to provide information about BIM (Business Information Management) and its various categories, along with details about trainers, the home section, about section, footer, and its responsive design.

## Features

### 1. **BIM Calculator**
   - A dedicated tool for calculating BIM-related metrics.
   - Easy to use and designed for accuracy.

### 2. **BIM Categories**
   - Detailed categorization of BIM topics.
   - Organized for easy navigation and user understanding.

### 3. **Trainer Section**
   - Highlights information about trainers.
   - Includes their expertise and background.

### 4. **Home Section**
   - Welcomes users with an intuitive and visually appealing design.
   - Provides quick navigation to important sections of the website.

### 5. **About Section**
   - Shares the purpose and mission of the website.
   - Provides an overview of the services offered.

### 6. **Footer**
   - Contains important links and contact information.
   - Social media links for staying connected.

### 7. **Responsive Design**
   - Fully responsive across all devices.
   - Ensures a seamless user experience on desktops, tablets, and mobile devices.

## Technologies Used

- **HTML**: For the structure of the website.
- **CSS**: For styling the website.
- **Tailwind**: For modern, responsive design.
- **JavaScript**: For interactivity and dynamic features.

## Installation

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/wptasmina/gime-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd gime-website
   ```
3. Open the `index.html` file in your browser to view the website.
